## Feature Engineering

This section covers hands-on practice of Feature Engineering concepts
using Python and Scikit-learn.

### Topics Covered
- Handling missing values
- Handling Imbalance Dataset
- Handling Outliers
- Encoding categorical features (Nominal, OHE, Label, Ordinal, Target Guided Ordinal Encoding)
- Feature scaling and normalization
- Feature transformation
- Practical examples with sample datasets

### Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
