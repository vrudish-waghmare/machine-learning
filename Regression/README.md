## Regression Algorithms

This folder contains implementations and experiments with regression models.

### Algorithms
- Linear Regression
- Polynomial Regression

### Key Concepts
- Cost function (MSE)
- Feature scaling
- Overfitting vs Underfitting
- Model evaluation using R² score
- Performance Metrics (mean_squared_error, mean_absolute_error, root_mean_squared_error, adjusted_r2_score)
